What do I need to run it?

Claude Code, plus Node and Python on your computer. It asks before installing anything else (it uses Playwright to load your pages).

Does it work on my local dev server?

Yes. Give it a localhost address, your repo, or screenshots. Live URLs give the most complete check.

Is this the same as real user research?

No. It catches common, well-understood problems fast. It can't tell you whether people want your product. For that, a First-Use Test shows real people using it.

Can I use it more than once?

Yes. Run it as often as you like, on any project.
